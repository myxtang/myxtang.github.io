# myxtang.github.io

Personal academic website of Michael Tang, live at **https://myxtang.github.io**.

Built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll template. Every push to `main` rebuilds the site automatically (see the **Actions** tab); changes appear a few minutes later.

## Where things live

| To change…                       | Edit this file                                                      |
| -------------------------------- | ------------------------------------------------------------------- |
| Bio, photo caption, home page    | `_pages/about.md`                                                   |
| Photo                            | `assets/img/prof_pic.jpg` (replace the file, keep the name)         |
| Publications                     | `_bibliography/papers.bib` (add `selected = {true}` to feature one) |
| News items on the home page      | `_news/` (one small `.md` file per item; copy an existing one)      |
| CV page                          | `_data/cv.yml`                                                      |
| CV PDF                           | `assets/pdf/Michael_Tang_CV.pdf` (replace the file, keep the name)  |
| Email, GitHub, Scholar links     | `_data/socials.yml`                                                 |
| Name, site description, settings | `_config.yml`                                                       |

The template's own documentation is in [`docs/`](docs/README.md).
